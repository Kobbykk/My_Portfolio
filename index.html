Real-time streaming

Streaming Pipeline with Change Data Capture

github.com/Kobbykk/rides-streaming
  • Apache Kafka (Redpanda)
  • Debezium
  • PostgreSQL
  • Python
  • Docker
  • Built a Kafka producer and consumer sustaining about 2,200 events per second. The consumer commits offsets only after a durable write, which guarantees at-least-once delivery.
  • Got exactly-once results with an idempotent sink keyed on event UUID. Replaying 8,958 events wrote zero duplicate rows.
  • Configured Debezium change data capture over PostgreSQL logical replication, which captures deletes that timestamp-based polling misses.
