# Edwin Addai | Data Engineer Portfolio

Personal portfolio site: three data engineering projects (batch ELT warehouse with dbt and Airflow, AWS lakehouse with S3, Glue and Athena, Kafka streaming with Debezium CDC), plus experience, skills, education and contact.

It is one static page (`index.html`) with no build step.

## Publish with GitHub Pages
1. Open this repo's **Settings > Pages**.
2. Set **Source** to "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
3. After a minute the site is live at https://kobbykk.github.io/My_Portfolio/

## Update it
Edit `index.html` and commit. Screenshots go in an `images/` folder and are added with `<img src="images/name.png" alt="...">`.
